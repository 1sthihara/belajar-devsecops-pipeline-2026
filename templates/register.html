Security Documentation

Application Security

Dokumentasi mengenai mekanisme pengujian keamanan, kualitas kode, dependency, dan container pada Sentinel Flask Application.

1. Security Overview

Sentinel menerapkan pendekatan DevSecOps dengan mengintegrasikan pemeriksaan keamanan ke dalam proses CI/CD.

  • Source code security analysis.
  • Automated code quality checking.
  • Python dependency vulnerability scanning.
  • Docker container vulnerability scanning.
  • Automated deployment melalui GitHub Actions.

2. Security Testing Tools

Semgrep - Static Application Security Testing

Menganalisis source code untuk mendeteksi pola kode yang berpotensi menimbulkan kerentanan keamanan.

Pylint - Code Quality Analysis

Memeriksa kualitas, struktur, konsistensi, dan potensi masalah pada kode Python. Pipeline menetapkan minimum score 9.0/10.

pip-audit - Dependency Security

Memeriksa dependency Python untuk menemukan kerentanan yang diketahui berdasarkan informasi vulnerability database.

Trivy - Container Security

Memindai Docker image untuk mengidentifikasi kerentanan pada operating system packages dan dependency yang terdeteksi.

3. Docker Security Practices

Container Sentinel menerapkan beberapa praktik keamanan dasar:

  • Menggunakan Python Slim sebagai base image.
  • Melakukan pembaruan paket sistem operasi.
  • Menggunakan user non-root bernama appuser.
  • Membatasi direktori kerja aplikasi pada /app.
  • Menggunakan Docker untuk isolasi lingkungan aplikasi.

Contoh konfigurasi keamanan Docker:

USER appuser EXPOSE 5000 CMD ["python", "app.py"]

4. CI/CD Security Workflow

Pipeline menjalankan tahapan pemeriksaan sebelum aplikasi dideploy ke target VM.

Git Push | v Semgrep SAST | v Pylint Code Quality | v pip-audit | v Docker Build | v Trivy Image Scan | v Deploy to VM

5. Application Configuration

  • Framework: Python Flask
  • Container: Docker
  • Application Port: 5000
  • Database: Tidak digunakan
  • Authentication: Tidak diimplementasikan
  • CI/CD: GitHub Actions
  • Deployment: Self-hosted Runner
Security Notice
Aplikasi ini merupakan demonstrasi implementasi DevSecOps dan tidak menyediakan autentikasi pengguna. Halaman aplikasi dapat diakses tanpa login. Jangan mengekspos aplikasi ke jaringan publik apabila terdapat informasi sensitif.
