CI/CD Pipeline Workflow

Proses otomatis untuk memeriksa kualitas kode, keamanan dependency, dan keamanan container sebelum deployment.

01. SAST Semgrep melakukan analisis keamanan source code.
02. Quality Pylint memeriksa kualitas kode dengan minimum score 9.0.
03. Dependency pip-audit memeriksa kerentanan library Python.
04. Container Docker Build dan Trivy melakukan pemeriksaan image.
